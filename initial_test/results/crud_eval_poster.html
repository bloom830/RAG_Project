🔄 优化动作
第 1 轮

超长文本兜底截断

智谱 Embedding API 对单条长度有限制，加入自动截断与分批处理，避免 Embedding 调用失败导致检索为空。

第 2 轮

检索重排序

向量召回 Top-10 后，按 query 关键词在 chunk 中的命中密度重新排序，取 Top-5 进入生成，提升相关 chunk 的优先级。

第 3 轮

BM25 + FAISS 混合检索

用 RRF 融合向量检索与关键词检索结果，兼顾语义相关性与关键词命中，降低漏召风险。

第 3 轮

Cross-Encoder 重排序

混合检索召回 Top-10 候选后，使用 BAAI/bge-reranker-base 对 query-chunk 对进行相关性打分，取 Top-5 进入生成。
