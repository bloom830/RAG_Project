🔄 优化动作
第 1 轮

超长文本兜底截断

智谱 Embedding API 对单条长度有限制，加入自动截断与分批处理，避免 Embedding 调用失败导致检索为空。

第 2 轮

检索重排序

向量召回 Top-10 后，按 query 关键词在 chunk 中的命中密度重新排序，取 Top-5 进入生成，提升相关 chunk 的优先级。
